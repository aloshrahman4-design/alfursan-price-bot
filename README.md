# بوت تعديل صور الأسعار — عيون الفرسان (خط الجملة)

بوت تيليجرام مستقل: يستقبل صورة منتج مع نص السعر (كـ caption)،
ويرجع نفس الصورة وفيها صندوق أسود بنص ذهبي يحتوي السعر،
بموقع يتكيف تلقائياً حسب أهدأ زاوية بالصورة.

## الملفات
- `bot.py` — البوت نفسه (polling + خادم صغير لأجل UptimeRobot)
- `price_stamp.py` — منطق تحليل الصورة ورسم صندوق السعر
- `Cairo.ttf` — الخط العربي المستخدم
- `requirements.txt` — المكتبات المطلوبة

## خطوات الإنشاء والنشر

### 1. إنشاء بوت جديد بتيليجرام
- افتح محادثة مع **@BotFather**
- أرسل `/newbot` واتبع التعليمات (اسم + username ينتهي بـ bot)
- راح يعطيك **Token** — احتفظ فيه، تحتاجه بالخطوة الجاية

### 2. رفع الكود على GitHub
سوي مستودع جديد منفصل (مثلاً `alfursan-price-bot`) وارفع هذا المجلد بالكامل.

### 3. إنشاء خدمة جديدة على Render
- Render Dashboard → New → Web Service
- اربطه بمستودع GitHub الجديد
- Environment: Python 3
- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`
- أضف Environment Variable:
  - `BOT_TOKEN` = التوكن اللي أعطاك ياه BotFather

### 4. منع نوم الخدمة (Free tier)
نفس طريقة بوت المتجر: سوي مونيتر جديد على UptimeRobot يراقب رابط
الخدمة (`https://your-service-name.onrender.com`) كل 5 دقائق.

### 5. الاستخدام
افتح محادثة مع البوت الجديد بتيليجرام، أرسل صورة المنتج واكتب
نص السعر بنفس خانة الكتابة (caption) — مثلاً:
```
12 زوج
67 الف
```
البوت يرجعلك نفس الصورة جاهزة خلال ثواني.

## ملاحظات
- النص يقدر يكون أكثر من سطر (يفصل الأسطر بالضغط على Enter بالكتابة).
- الصندوق دائماً أسود والنص ذهبي — موحّد لكل صفحات الجملة الست.
- لو ما كتبت نص مع الصورة، البوت يطلب منك ترسلها ثانية مع النص.
